# job-radar

Собирает вакансии с hh.ru, из каналов Телеграма и лент RSS, отсеивает лишнее, оценивает каждую нейросетью под профиль кандидата и присылает в Телеграм подборку подходящих. Конвейер на n8n.

## Как работает

1. Источники перечислены в `src/sources.json`: поиски hh.ru (через их RSS), публичные каналы Телеграма (страница `t.me/s/<канал>`), любые ленты RSS.
2. Отбор без нейросети: свежесть, ключевые слова, стоп-слова в заголовке, повторы ссылок и одна и та же вакансия в разных каналах. Правила в `src/filter.config.json`.
3. Нейросеть получает профиль из `src/profile.md` и текст вакансии, отвечает оценкой от 0 до 10, компанией, зарплатой, форматом работы и одной фразой, почему такая оценка.
4. Вакансии с оценкой не ниже порога приходят одним сообщением, лучшие сверху.

Каждая вакансия попадает в журнал SQLite один раз. У отсеянных записана причина: старое объявление, стоп-слово, нет ключевых слов, похожая уже была, ниже порога.

Пример подборки:

```
Подходящие вакансии: 2

Стажёр Python-разработчик · Пример
удалённо
9/10: Python, боты и FastAPI, опыт не требуется
@job_python

Junior разработчик чат-ботов · Другая компания
от 60 000 ₽ · гибрид
8/10: n8n и нейросети, подходит уровень
hh.ru: Python без опыта
```

## Запуск

Docker, ключ нейросети с совместимым с OpenAI интерфейсом и бот Телеграма. Подробно в `docs/setup.md`.

## Разработка

Код узлов лежит в `src/`, в конвейер `workflows/collect.json` его вклеивает `npm run build`; после отправки в main это же делает проверка на Гитхабе и сама коммитит результат. Тесты `npm test` прогоняют конвейер целиком на подменённых страницах hh.ru и канала, без сети. Нужен Node 22.5 или новее.
