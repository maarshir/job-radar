- `score.md`: оценка объявления под профиль кандидата. Поля `{{profile}}`, `{{title}}`, `{{text}}`, `{{source}}`, `{{link}}`, `{{letter_min}}` подставляет узел «Промпт». Для вакансий с оценкой от `letter_min` (порог, но не выше 5) нейросеть сразу пишет сопроводительное письмо, чтобы оно было и у вакансий ниже порога, которые можно запросить из бота. Ответ разбирает `src/parse.js`.
