Код узлов Code для n8n. Файлы без сторонних зависимостей, каждый можно вклеить в узел целиком.

- `text.js`: разбор сущностей HTML, текст без тегов, первая строка поста.
- `rss.js`: разбор лент RSS 2.0 и Atom в записи `{ title, link, text, date }`.
- `telegram.js`: разбор страницы `t.me/s/<канал>`: посты с текстом, ссылкой и датой; цитаты из ответов и посты без текста пропускаются.
- `sources.js` и `sources.json`: список источников, адреса поиска hh.ru собираются из параметров.
- `filter.js` и `filter.config.json`: отбор по свежести, ключевым словам и стоп-словам в заголовке, отсев повторов по ссылке (без меток hh.ru и utm) и по похожему тексту. Каждый отказ с причиной.
- `journal.js`: журнал в SQLite (`node:sqlite`, Node 22.5+). Одна запись на ссылку, статусы `collected`, `rejected`, `matched`; `forget` убирает незакрытую запись, если нейросеть не ответила.
- `parse.js`: разбор ответа нейросети, проверка шкалы и порога.
- `message.js`: подборка для Телеграма с разметкой HTML, длинная делится на несколько сообщений.
- `fill.js`: подстановка полей в шаблон промпта.
- `profile.md`: описание кандидата для нейросети.
- `nodes/`: код узлов конвейера. Строки `// @include` при сборке (`npm run build`) заменяются файлами выше.
